# Controller Input Diagnostics

PS4 / PS5 コントローラを Android の Bluetooth 設定から接続し、アプリに届く入力を確認するための Android Studio プロジェクトです。Bluetooth をアプリから直接扱わず、Android の標準入力イベントだけを監視します。

## 実装済み（第1段階）

- 接続されたゲームコントローラの名前、ID、入力ソースの表示
- 左右スティック、L2/R2、代表的な各軸の生値表示
- ボタンの押下・解放イベントの履歴表示
- タッチパッド由来の `DOWN` / `MOVE` / `UP` と座標・ソースの履歴表示
- タッチパッドの上・下スワイプ、および左右の上端から下端への対角急停止ジェスチャー判定
- コントローラの接続・切断の検出

## 開き方

1. Android Studio の **Open** でこのフォルダを選択します。
2. Gradle Sync を完了させます。
3. 実機を接続して実行します。PS4 / PS5 コントローラは、先に Android の Bluetooth 設定画面でペアリングしてください。
4. アプリを前面にした状態でコントローラを操作し、表示される軸名・値・イベント履歴を確認します。

機種、Android バージョン、接続方式で軸の割り当てやタッチパッドの届き方は異なります。画面に表示されるイベント履歴を基に、対象端末での実際の挙動を記録してください。

## 未実装（次段階）

入力の正規化、デッドゾーン、操作値への割り当て、推進速度の保存、コントローラ有効化状態、通常操作画面は、診断結果を確定してから追加する想定です。
